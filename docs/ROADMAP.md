# 프로젝트 로드맵

향수·뷰티 제품의 향 카테고리를 탐색하고 네이버 쇼핑에서 관련 상품을 연결하는 중개 서비스.

---

## 현재 구현 완료

- **백엔드**: FastAPI + MongoDB
- **향 탐색 UI**: 제품 → 향 계열 → 세부 향 드릴다운 네비게이션
- **상품 표시**: 수동 큐레이션 상품 데이터 카드 표시 + 가격 낮은순/높은순 정렬
  (~~Naver Shopping API 연동~~ 2026-07-31 서비스 종료로 중단, 상세는 `프로젝트-개발-기록.md` 참고)
- **프론트엔드**: 정적 HTML + CSS + Vanilla JS (빌드 도구 없음)
- **헬스체크**: `/health` 엔드포인트 (서버·MongoDB 상태 확인)

---

## Phase 1 — 검색 품질 개선 (단기)

> 목표: 향에 따라 검색 결과가 0건인 문제를 줄이고 상품 매칭 정확도를 높인다.

- [ ] `scripts/curated_products_template.csv` 실제 상품 데이터로 채우고 적재 (14개 조합 × 3~5개 상품)
- [ ] 큐레이션 상품 가격 주기적(월 1회) 재확인·갱신 루틴 정하기
- [ ] ~~향별 동의어·대체 표기 목록 추가~~ / ~~Naver API 검색 쿼리 다양화~~ — 실시간 검색 중단으로 해당 없음
- [ ] 상품이 없는 조합일 때 대체 UI 처리 (안내 메시지, 유사 향 추천 등)

---

## Phase 2 — 중개 사이트 완성 (중기)

> 목표: 판매가 아닌 탐색·연결에 집중한 서비스 경험을 완성한다.

- [ ] 상품 카드 디자인 고도화 (이미지 비율, 판매처 강조, 가격 가독성)
- [ ] 향 카테고리 데이터 확장 (제품 유형·향 종류 추가)
- [ ] 제품 유형별 랜딩 페이지 UI/UX 개선
- [ ] 외부 링크(네이버 쇼핑) 클릭 추적 및 사용자 흐름 개선

---

## Phase 3 — 커뮤니티 기능 (장기)

> 목표: 각 제품·향에 대한 사용자 의견을 나눌 수 있는 커뮤니티를 추가한다.
> 이 시점에 프론트엔드를 Next.js로 전환한다.

- [ ] **프론트엔드 전환**: Next.js App Router + Tailwind CSS + shadcn/ui + Zustand
- [ ] 사용자 인증 (로그인·회원가입)
- [ ] 제품·향별 리뷰 및 의견 작성·조회
- [ ] 커뮤니티 전용 API 엔드포인트 추가 (FastAPI 백엔드 확장)
- [ ] 좋아요·댓글 등 소셜 인터랙션
